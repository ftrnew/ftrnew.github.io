# Keluarga NSPV Website

Website resmi untuk komunitas gaming **Keluarga NSPV** - sebuah ruang kebersamaan yang menghubungkan pemain dari berbagai penjuru Indonesia.

## 🎮 Tentang NSPV

Didirikan pada tahun 2019, KELUARGA NSPV tumbuh dari sekadar komunitas gaming menjadi ruang kebersamaan yang menghubungkan pemain dari berbagai penjuru Indonesia. Kami hadir untuk membangun koneksi, memberikan dukungan, dan membuka peluang bertumbuh bagi semua anggota tanpa memandang latar belakang.

## ✨ Fitur Website

- **Desain Modern**: Interface yang estetik dengan gradien purple dan animasi smooth
- **Responsive Design**: Tampilan optimal di desktop dan mobile
- **Smooth Navigation**: Navigasi yang halus dengan scroll animation
- **Interactive Elements**: Hover effects dan micro-interactions
- **Core Values**: Showcase nilai-nilai komunitas dengan visual yang menarik
- **Testimonials**: Testimoni dari anggota komunitas dengan foto asli
- **Process Flow**: Langkah-langkah bergabung yang jelas dan mudah dipahami

## 🛠️ Teknologi

- **React 19** - Frontend framework
- **Vite** - Build tool dan dev server
- **Tailwind CSS** - Utility-first CSS framework
- **Framer Motion** - Animation library
- **Lucide React** - Icon library
- **shadcn/ui** - UI component library

## 🚀 Cara Menjalankan

1. Clone repository ini
2. Install dependencies:
   ```bash
   npm install
   ```
3. Jalankan development server:
   ```bash
   npm run dev
   ```
4. Buka browser dan akses `http://localhost:5173`

## 📦 Build untuk Production

```bash
npm run build
```

File hasil build akan tersimpan di folder `dist/`.
